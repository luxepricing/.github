# Security Policy

Luxe Pricing takes the security of our products and services seriously. If you believe you have found a security vulnerability in any Luxe Pricing repository, website, or service, please report it to us as described below.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.**

Submit reports through our security portal:

https://luxepricing.atlassian.net/servicedesk/customer/portal/106/create/204

Please include as much of the following as you can:

- The affected product, URL, or repository
- A description of the issue and its potential impact
- Step-by-step instructions to reproduce it
- Any proof-of-concept code, screenshots, or logs

## What to Expect

- We will acknowledge your report and keep you informed as we investigate.
- We ask that you give us reasonable time to resolve the issue before any public disclosure.
- Please make a good-faith effort to avoid privacy violations, data destruction, and service disruption while researching.

Our machine-readable contact information is published at [`/.well-known/security.txt`](.well-known/security.txt) per [RFC 9116](https://www.rfc-editor.org/rfc/rfc9116).
